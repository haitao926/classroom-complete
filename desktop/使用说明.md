# 桌面悬浮球

本客户端连接同包中的学校管理后台，不再使用旧版匿名接口。

## 日常使用

1. 启动管理后台，在“教室与设备”中创建设备并复制绑定码。
2. 双击“启动悬浮球.bat”（macOS/Linux 下可执行 `npm start`）。
3. 点击悬浮球，再点“设置”。填写服务器地址与设备绑定码，保存并连接。
4. 客户端打开后会在顶部明确显示“当前教室”；教室由设备绑定码确定。服务器再根据该教室和课表确定当前上课班级；若未排课可手动选班。
5. 点学生姓名直接录音；录音完成后先写入本机待上传队列，再自动上传到服务器。默认录完收起，可在设置中勾选保持展开。

- **快捷键**：`Ctrl+Shift+Space`（macOS 为 `Cmd+Shift+Space`）一键切换展开/收起。
- **退出与交互**：右键圆球弹出菜单可退出；拖动圆球松开后会自动吸附到屏幕边缘并记住坐标。
- **安全机制**：录音开始时锁定当前选中的学生与班级，录音期间不可切班。

## 生成安装包（打包分发）

已配置国内高速镜像源（`desktop/.npmrc`），打包时将自动从镜像源下载 Electron 及打包二进制工具，避免网络超时或 403 错误。

### 1. Windows 平台打包

- **标准安装包（NSIS 安装向导）**：
  双击执行 `生成Windows安装包.bat` 或在终端运行：
  ```bash
  npm run dist:win
  ```
  产物为标准安装向导程序，支持自定义安装路径，自动创建桌面和开始菜单快捷方式。

- **绿色免安装版（Portable 单文件便携版，机房推荐）**：
  双击执行 `生成Windows绿色免安装包.bat` 或在终端运行：
  ```bash
  npm run dist:win:portable
  ```
  产物为单个 `.exe` 文件，**无需管理员权限**，可直接存放在 U 盘或机房公共盘，即点即用。

- **同时生成上述两种格式**：
  ```bash
  npm run dist:win:all
  ```

### 2. macOS 平台打包

- **生成 DMG 安装包**：
  在终端执行：
  ```bash
  ./打包Mac安装包.sh
  # 或直接运行
  npm run dist:mac
  ```
  - 支持指定架构构建：`npm run dist:mac:arm64`（Apple Silicon）或 `npm run dist:mac:x64`（Intel）。
  - 支持 Universal 双架构：`npm run dist:mac:universal`。

### 3. 开发测试排查（免压缩打包）

若只需验证应用文件组装是否完整，可执行：
```bash
npm run pack
```
该命令会将未压缩的应用程序结构直接输出到 `desktop/dist` 对应平台的目录中，速度极快，便于排查资源路径问题。

## 网络与离线队列说明

- 教室机填写的服务器地址：若后台部署在另一台服务器/教师电脑，请填写该主机的局域网 IP（例如 `http://192.168.1.100:3000`）。
- 录音离线容灾：录音完成后即写入本地 SQLite/JSON 队列，即使网络闪断或重启悬浮球，后台恢复连接后也会自动续传。
