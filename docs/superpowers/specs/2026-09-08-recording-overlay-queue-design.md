# 录音浮层与待上传队列设计

## 目标

点击学生后立即开始录音，在当前窗口内显示始终可见的录音浮层。教师点击“完成记录”时停止录音并自动保存、上传，不需要滚动页面。

## 交互

- 录音浮层固定在窗口底部，覆盖座位表下缘而不参与页面布局。
- 浮层显示学生姓名、录音计时、文字补充、取消和完成记录按钮。
- 完成时按钮进入“保存中”状态；成功后收起，失败时写入本机队列并明确提示。
- 右下角待上传数量是按钮，点击打开队列弹窗，显示学生、时间、服务器、失败原因和重试操作。

## 队列规则

- 每条记录独立重试，一条失败不能阻塞后面的记录。
- `localhost` 旧记录保留原地址并显示原因，避免把演示学生误写入学校数据；用户可在队列弹窗中明确删除。
- 成功上传后从队列删除；失败记录保存最后错误与尝试时间。

## 验证

- 纯函数测试覆盖服务器地址迁移和逐条重试结果。
- Electron 源码语法检查、应用打包检查和实际运行检查。
- 生成 Windows x64 安装版与免安装便携版。
