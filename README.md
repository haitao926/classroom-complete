# 课堂随记 · 完整源码版

这是统一的学校应用：桌面悬浮球采集 + 班主任工作台 + 学校管理后台 + 语音转写/大模型处理任务。后台不需要npm安装第三方依赖，只需要 **Node.js 24或更高版本**。

## 立即运行

Windows：安装Node.js 24，解压，双击 **启动管理后台.bat**。

macOS/Linux/命令行：进入项目目录，运行 `npm start` 或 `node server.js`，打开 **http://localhost:3000**。

第一次打开创建学校管理员账号（密码至少10位），没有预置账号或公开密码。初始包含信息房1、信息房2、信息房3，无虚构学生或评分。

如果浏览器打开早于服务启动，刷新一次即可。服务端数据保存于 `data/`；停止后重新启动仍保留。

## 第一次配置顺序

1. **信息导入 → 教室课次总表（推荐）**：以“教室ID”为唯一标识上传，每行代表一名学生在一个教室课次中的确定安排，字段包括教室ID、教室名称、日期/星期、节次、教师、课程、班级、学号、姓名、行、列。系统会自动创建或更新教室、学生、座位和课表；同一教室课次允许多行学生，但班级、教师、课程必须一致。模板位于templates和网页下载入口。
2. **信息导入 → 学生名单**：上传.xlsx/UTF-8 CSV，选择工作表、表头行和字段。预览无误后确认。班级随名单建立。
3. **信息导入 → 座位安排**：按学号、班级、教室、行、列导入；也可以粘贴Excel六行六列姓名/学号矩阵。同名学生使用学号。空座保留。每班在不同信息房的座位可以不同。
4. **信息导入 → 课程安排**：地点、班级、教师、课程、星期、第几节课；可选具体日期和单双周。每节课的开始/结束时间由“课程安排 → 学校与节次设置”统一维护，教师和导入文件不需要填写。冲突会阻止导入。旧版.xls请另存.xlsx；合并表格需核对空值，不会自动猜测填充。
5. **课程安排**：设置学校节次（每一节对应一个开始/结束时间段）和学期起点，系统以北京时间和第1周起点计算单双周。课表与临时调课只选择第几节，不填写具体时间。
6. **账号与权限**：创建班主任/任课教师账号，并选择可访问班级；管理员可访问全校。
7. **教室与设备**：为每台教室电脑生成绑定码，仅显示一次。复制到悬浮球设置，日常上课教师无需登录。
8. **分析服务**：配置语音转写和大模型的完整接口地址、模型名与密钥。

## 真实服务接入

语音转写调用兼容标准音频转写的HTTP接口：POST multipart/form-data，含 `file`、`model`、`response_format=json`，响应需包含 `text`。例路径 `/v1/audio/transcriptions`。

大模型调用 Chat Completions兼容接口：POST JSON，含 `model`、`messages`，读取 `choices[0].message.content`。例路径 `/v1/chat/completions`。支持独立配置转写和大模型服务，也支持无密钥的本地兼容服务。

系统自动发送评价规则，要求事实摘要、行为事实、评价维度、分值、原文证据与理由。输出通过结构、分值范围、维度唯一性和原文证据检查后，进入“待审核”。不是关键词打分，也没有生产环境模拟结果。

需要自行提供可用服务及密钥。**代码已实现真实HTTP调用，但本交付未使用你的真实服务跑付费请求**。未配置服务时音频和任务仍可靠保存，显示“等待服务配置”；保存配置后自动继续。失败任务最多自动尝试3次，可人工重试。

## 班主任工作流

登录后只看到授权班级。班级概览查看记录与覆盖情况；课堂记录按班级、学生、日期、状态筛选；学生档案进入该学生历史；记录详情可回听音频、修正转写、查看评分依据、填写正式分数并确认。也可选择不计分，仅确认事实。导出CSV包含规则版本和正式评价。

音频与文字提交时即归档到学生、班级、教室和课堂。模型不决定身份。设备记录中的教师来自课表，表示计划任课教师，不代表操作者身份已登录验证。确认后的记录不可被自动重跑覆盖，所有修改与审核留痕。

## 随堂采集：网页端与客户端双模支持

课堂端按教室设备、北京时间、日期和第几节课自动匹配班级、教师、课程及座位。教师正常进入教室后无需登录或选择班级；系统以课表中的计划任课教师作为课堂教师。临时代课、调课或换教室时，在桌面悬浮窗点击“调换课”，选择日期、第几节和完整课次（班级、教师、课程）即可，本节结束后自动恢复固定课表。

系统原生支持 **桌面客户端（悬浮球）** 与 **网页端采集终端** 两种使用途径，互为补充：

1. **桌面客户端（Electron 悬浮球）**：
   - 适合安装在机房教师机/受控电脑上，开机自启、贴边吸附，点击展开座位表直接录音。
   - 依赖与打包：在 `desktop/` 目录下提供已配好国内加速镜像的打包脚本（支持 Windows NSIS、免管理员权限绿色便携版 Portable，以及 macOS DMG 安装包）。
   - 详见 `desktop/使用说明.md`。

2. **网页端采集终端（免安装，即开即用）**：
   - 直接在任意现代浏览器中打开：`http://服务器地址:3000/classroom.html`。
   - **免密设备模式**：在“教室与设备”中生成绑定码后，可直接生成并复制专属网页链接（如 `http://.../classroom.html?token=xxx`）。机房电脑存为浏览器书签后，无需输入任何账号密码，打开即自动识别教室、课表当前节次班级并加载 6x6 座位表。
   - **移动与触屏友好**：完美适配 iPad/Android 平板、触屏教学一体机及普通电脑浏览器，支持全屏模式与离线断网缓存（IndexedDB 本地队列，网络恢复自动续传）。
   - **登录态直通**：登录管理后台的教师也可在工作台顶部一键直达全屏采集端。

## 部署和备份

默认监听0.0.0.0:3000。多人访问时，在同一局域网访问服务器IP:3000；正式对外访问应通过HTTPS反向代理，并设置环境变量COOKIE_SECURE=1。不要直接公开未完成初始化的服务。

可使用 `docker compose up -d --build`；Docker配置已提供但未在本环境执行。数据位于持久卷。

备份：`npm run backup`。输出到backups，含数据库、音频和服务密钥加密文件。建议暂停新录音与处理后执行，得到一致时间点的数据。恢复时停止后台，将备份的classroom.sqlite、audio和secret.key放入DATA_DIR；清除旧的sqlite-wal/sqlite-shm后启动。密钥文件必须与数据库一起备份。

使用环境变量PORT、HOST、DATA_DIR、COOKIE_SECURE配置部署；.env.example是示例，复制.env后可用 `npm start` 启动（脚本会加载 `.env`）。

AI服务也支持通过本地 `.env` 配置：`ASR_URL`、`ASR_MODEL`、`ASR_API_KEY`、`LLM_URL`、`LLM_MODEL`、`LLM_API_KEY`。`.env` 已被 `.gitignore` 忽略，真实密钥不要提交到代码仓库。环境变量优先于后台数据库中的服务配置；当前项目的ASR适配仍要求兼容 `multipart/form-data` 的转写接口。

## 代码结构

- server.js：HTTP接口、权限、导入及课堂归属。
- lib/db.js：SQLite数据库与默认评价规则。
- lib/ai.js：持久任务、转写、大模型分析和输出验证。
- lib/import.js：CSV/XLSX读取。
- lib/security.js：密码哈希与服务密钥加密。
- public/：班级工作台、管理页面与备用课堂端。
- desktop/：Electron悬浮球客户端。
- tests/：隔离集成与格式读取测试。

## 当前明确边界

本版适合单校统一服务器部署，包含权限、持久任务和备份入口；未实现多学校租户隔离、跨机任务集群、账号自助找回、安装包自动更新。导入支持明细表映射，不会自动理解任意排版的周课表图片/PDF。自动评分默认待人工确认，无学生排名或缺记录计零分。
